# Урок 4.2 — Next.js + Vercel с нуля

> **Зачем:** Claude Code создаёт проект, ты деплоишь на Vercel за 2 минуты. Без предварительного опыта.

---

## Промт для старта проекта

```
У меня есть SPEC для проекта [название].

[вставь свой SPEC.md]

Создай Next.js 14 проект (App Router) с Tailwind CSS.
Структура папок, базовые компоненты, главная страница.
Деплой будет на Vercel.

Начни с минимальной рабочей версии.
```

---

## Деплой на Vercel — 3 шага

1. Создай аккаунт на [vercel.com](https://vercel.com) (бесплатно)
2. Подключи GitHub репозиторий с проектом
3. Нажми Deploy — готово

Vercel автоматически деплоит каждый раз когда ты пушишь изменения.

---

> [!NOTE] Если нет опыта с GitHub
> Claude Code поможет с git командами. Напиши: "Я не знаком с git — объясни пошагово как залить проект на GitHub".
