# Урок 5.2 — MCP — подключение внешних данных

> **Зачем:** Claude может получать данные напрямую из Google Sheets, Slack, или Amazon — без ручного копирования.

---

## Что такое MCP

MCP (Model Context Protocol) — протокол который позволяет Claude подключаться к внешним источникам данных и инструментам.

Без MCP: ты копируешь данные из Sheets → вставляешь в Claude → получаешь результат → копируешь обратно.

С MCP: Claude сам читает из Sheets, обрабатывает, записывает результат обратно.

---

## Примеры для нашей работы

- Claude читает еженедельные данные из Google Sheets → генерирует отчёт → записывает в другой лист
- Claude получает новые отзывы с Amazon → анализирует → отправляет summary в Slack
- Claude проверяет листинги → находит проблемы → создаёт задачи в Notion

---

> [!NOTE]
> MCP настраивается один раз. После этого автоматизация работает без ручного вмешательства.
