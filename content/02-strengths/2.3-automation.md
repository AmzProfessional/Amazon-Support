# Урок 2.3 — Внутренние инструменты и автоматизация

> **Зачем:** Часть рутинных задач можно передать Claude полностью — без кода, прямо сейчас.

---

## Что автоматизируем без кода

- Ответы покупателям на типовые вопросы
- Шаблоны ответов на негативные отзывы
- Чеклист запуска нового продукта
- Бриф для команды после анализа данных

---

## Референс-промт — ответ на негативный отзыв

```
Ты менеджер поддержки Amazon-бренда [название].
Тон: дружелюбный, не защитный, ориентированный на решение.

Отзыв покупателя: [вставить текст]
Рейтинг: [1–3 звезды]

Напиши ответ который:
— признаёт проблему без оправданий
— предлагает конкретное решение
— заканчивается позитивно
— до 100 слов, без шаблонных фраз типа "Нам жаль слышать"
```

Полная версия: [[../prompts/negative-review-prompt|Negative Review Prompt →]]

---

> [!WARNING] Spot the Mistake
> ```
> Ответь на этот негативный отзыв: [отзыв]
> ```
> **Проблемы:** нет тона, нет ограничения на длину, нет правил. Claude напишет длинный корпоративный ответ с "Нам очень жаль" в начале.

---

## Проверь себя

> [!QUESTION] Закрой страницу и ответь
> 1. Назови 3 задачи которые автоматизируем без кода прямо сейчас.
> 2. Что должен содержать хороший ответ на негативный отзыв?
> 3. Почему важно указывать "до 100 слов"?

> [!SUCCESS] Действие
> Найди реальный негативный отзыв на один из наших продуктов. Запусти промт. Сравни с тем что написали бы вручную.
