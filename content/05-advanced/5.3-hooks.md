# Урок 5.3 — Hooks — Claude реагирует на события

> **Зачем:** Hooks позволяют Claude автоматически реагировать на события — без ручного запуска.

---

## Что такое Hooks

Hook — это триггер. Когда происходит событие → Claude запускается автоматически.

```
Событие: появился новый отзыв 1-2 звезды
→ Hook запускает Claude
→ Claude анализирует отзыв
→ Отправляет summary + рекомендацию в Slack
→ Создаёт задачу в Notion для менеджера
```

---

## Примеры хуков для нашей работы

- Новый конкурент в нише → автоматический анализ его листинга
- Падение BSR на 20%+ → уведомление с анализом причин
- Новая партия товара → автоматическая генерация Q&A для листинга

---

> [!NOTE]
> Hooks — самый продвинутый уровень. Начинать стоит после того как уверенно работаешь с агентами и MCP.
