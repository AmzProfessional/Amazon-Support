# Урок 0.2 — Десктопное приложение, цены и первая настройка

> **Зачем:** Три вещи которые нужно знать с самого начала — где скачать приложение, что входит в бесплатный план, и какие данные безопасно вставлять в Claude.

---

## Скачать Desktop App

**Mac / Windows:** [claude.ai/download](https://claude.ai/download)

Войди с тем же аккаунтом что и в браузере. Быстрее открывается, поддерживает Projects.

---

## Планы и цены — что важно знать

| План | Цена | Лимиты | Для кого |
|------|------|--------|----------|
| **Free** | Бесплатно | ~20–30 сообщений / 8 часов (Sonnet) | Попробовать, редкие задачи |
| **Pro** | ~$20/мес | В 5× больше сообщений, доступ к Opus | Регулярная работа |
| **Team** | ~$25/мес/чел | Всё из Pro + общие Projects | Команда |

> [!NOTE] Что делать когда закончились сообщения
> Бесплатный план показывает "You've reached your limit" — жди 8 часов или переключись на другую модель (Haiku расходует лимит медленнее).
> Для ежедневной работы с листингами и отчётами — Pro окупается за 1–2 задачи в день.

## Безопасность данных — что можно вставлять

> [!WARNING] Прочитай один раз и запомни
> **Можно вставлять:**
> - Отзывы покупателей (публичные данные с Amazon)
> - Тексты листингов и описания продуктов
> - Внутренние отчёты без персональных данных
> - Структуры таблиц и шаблоны документов
>
> **НЕ вставляй:**
> - Пароли, API-ключи, токены
> - Персональные данные клиентов (имена, адреса, emails)
> - Банковские данные и финансовые реквизиты компании
> - Конфиденциальные договоры с партнёрами

По умолчанию Anthropic не использует твои сообщения для обучения моделей (можно проверить в Settings → Privacy). Для максимальной защиты — используй Team план с отключённым обучением.

## Projects — главная фича для нашей работы

Project — это пространство с **постоянной памятью**. Один раз описываешь контекст — Claude помнит его во всех будущих чатах этого проекта.

```
Как использовать:

Project "Brand — [название]"
  → Контекст: что продаём, преимущества, аудитория, тон
  → Все листинги, отзывы, отчёты — в одном месте
  → Claude не спрашивает каждый раз "что за продукт"
```

**Создать:** New Project → назови → в «Project instructions» вставь:

```
Мы продаём [категория] на Amazon под брендом [название].
Целевая аудитория: [кто покупает].
Тон коммуникации: [профессиональный / дружелюбный].
Главные преимущества продукта: [список].
```

## Artifacts — быстрые прототипы в чате

Artifact — Claude создаёт не просто текст, а **живой объект** прямо в диалоге: таблицу, визуализацию, мини-сайт, калькулятор.

Когда полезно:
- Сравнительная таблица конкурентов
- Листинг в отформатированном виде
- Быстрый прототип страницы до написания кода

## Когда Claude отказывается — что делать

Иногда Claude отвечает «Я не могу помочь с этим». Не паникуй.

**Три причины и решения:**

```
Причина 1: Запрос слишком размытый
→ Добавь контекст: кто ты, зачем нужно, как будет использоваться

Причина 2: Формулировка похожа на запрещённый контент
→ Перефразируй: "помоги написать..." вместо "сделай..."

Причина 3: Задача слишком большая за один раз
→ Разбей на шаги: сначала структуру, потом детали
```

## Управление контекстом в длинных сессиях

Чем длиннее разговор — тем хуже Claude помнит начало. Признаки проблемы: начинает повторяться, "забывает" правила из начала сессии, качество ответов падает.

**Что делать:**
```
/clear    — очистить историю, начать чисто (контекст сбросится)
/compact  — сжать историю (Claude суммирует и продолжает)
```

Или просто начни новый чат — скопируй CLAUDE.md в начало и продолжай.

**Правило:** если сессия длиннее 30–40 сообщений — начинай новую.
