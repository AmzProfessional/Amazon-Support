## Три вещи которые нужно знать

### 1. Projects — главная фича для нашей работы

Project — это отдельное пространство с **постоянной памятью**. Один раз описываешь контекст — Claude помнит его во всех будущих чатах этого проекта.

```
Как использовать для нашей команды:

Project "Brand — [название]"
  → Контекст: что продаём, ключевые преимущества, аудитория, тон
  → Все листинги, отзывы, отчёты по этому бренду — в одном месте
  → Claude не спрашивает каждый раз "что за продукт"
```

> [!TIP] Создай Project сразу
> Нажми «New Project» → назови «[Название бренда]» → в поле «Project instructions» вставь:
> ```
> Мы продаём [категория] на Amazon под брендом [название].
> Целевая аудитория: [кто покупает].
> Тон коммуникации: [профессиональный / дружелюбный / и т.д.].
> ```

---

### 2. Artifacts — быстрые прототипы прямо в чате

Artifact — это когда Claude создаёт не просто текст, а **живой объект**: таблицу, визуализацию, мини-сайт, калькулятор — прямо внутри диалога.

Когда полезно:
- Попросить Claude сделать сравнительную таблицу конкурентов
- Быстро проверить как выглядит листинг в отформатированном виде
- Создать шаблон отчёта который можно сразу скопировать

---

### 3. Разница между чатом и Claude Code

| | Claude.ai / Desktop | Claude Code |
|---|---|---|
| Где открывается | Браузер или приложение | Терминал |
| Что умеет | Текст, анализ, генерация | Код, файлы, деплой |
| Кому | Вся команда | Тот кто строит инструменты |
| Когда в курсе | М0–М2 | М3–М5 |

---

> [!WARNING] Spot the Mistake
> Сотрудник начинает каждый новый чат с фразы: «Мы продаём беспроводные наушники на Amazon, наша аудитория — офисные работники...»
>
> **Что не так?** Это должно быть один раз написано в Project Instructions. Тогда Claude знает контекст всегда — не нужно повторять в каждом сообщении.
