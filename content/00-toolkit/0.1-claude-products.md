# Урок 0.1 — Где открывать Claude

> **Зачем:** Claude — это не одна программа. Есть несколько инструментов под разные задачи. Этот урок объясняет какой открывать и когда — чтобы не тратить время на лишнее.

---

## Четыре инструмента — четыре сценария

### 💬 Claude.ai / Desktop App
**Где:** [claude.ai](https://claude.ai) или приложение Mac/Windows
**Для кого:** вся команда
**Когда:** написать листинг, проанализировать отзывы, получить отчёт, сгенерировать ответ покупателю

Это основной инструмент для **М0–М2** курса. Большинству команды больше ничего не нужно.

---

### 🗂️ Cowork
**Где:** отдельное десктопное приложение (Beta)
**Для кого:** операционный менеджер, те кто автоматизирует рутину
**Когда:** Claude видит твой экран и управляет файлами и приложениями — без кода

Примеры задач: переименовать 200 файлов по правилу, собрать данные из нескольких таблиц, автоматически разложить документы по папкам.

> [!NOTE] Пока не установлен — не нужен
> Для прохождения М0–М4 Cowork не требуется. Вернись к нему когда будешь готов к автоматизации файловых задач.

---

### ⚡ Claude Code
**Где:** терминал (Mac: Terminal / Windows: PowerShell)
**Для кого:** тот кто строит инструменты для команды
**Когда:** нужно создать реальный продукт — сайт, дашборд, внутренний инструмент

Claude Code появляется в **М3** курса. До этого — не нужен. Установка объясняется пошагово когда придёт время.

---

### 🔌 API
**Где:** код или сервисы автоматизации
**Для кого:** разработчик
**Когда:** нужна автоматизация которая работает без участия человека 24/7

Это **М5 Advanced**. Большинству команды никогда не понадобится напрямую.

---

## Правило выбора

```
Нужен результат прямо сейчас?
  → Claude.ai или Desktop App

Автоматизация файлов на компьютере без кода?
  → Cowork

Строишь инструмент / сайт / дашборд?
  → Claude Code (с М3)

Нужна полная автоматизация без человека?
  → API (нужен разработчик)
```

---

> [!WARNING] Spot the Mistake
> Новый сотрудник хочет проанализировать отзывы конкурента. Он слышал про Claude Code и начинает его устанавливать.
>
> **Что не так?** Для анализа отзывов достаточно открыть [claude.ai](https://claude.ai) и вставить промт. Claude Code — это инструмент для создания продуктов, не для чат-задач. Выбор лишнего инструмента = потеря часа.
