# Урок 3.3 — Полный запуск + CLAUDE.md

> **Зачем:** Микро-тест прошёл — масштабируем. Параллельно создаём CLAUDE.md чтобы сохранить контекст.

---

## Полный запуск

После успешного микро-теста:
1. Берём 50–100 отзывов
2. Запускаем тот же промт
3. Получаем структурированный отчёт
4. Сохраняем результат

---

## Создаём CLAUDE.md для проекта

```markdown
# Проект: Анализатор отзывов конкурента

## Контекст
Инструмент для анализа отзывов Amazon. Команда продаёт через бренды.
Используется менеджерами для понимания слабых мест конкурентов.

## Как пользоваться
1. Скопировать отзывы с Amazon
2. Вставить в промт (шаблон в prompts/reviews-prompt.md)
3. Запустить в Claude Sonnet
4. Скопировать результат в отчёт команды

## Стек
Только Claude.ai — кода нет, всё через промт.

## Правила
- Всегда указывать название продукта конкурента
- Запускать на минимум 20 отзывах для репрезентативности
```
