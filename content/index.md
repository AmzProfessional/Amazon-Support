# Claude Code
## Внутренний курс для команды · Amazon / E-commerce

> [!quote] Зачем этот курс

## 📐 Принципы курса

> [!abstract] Через каждый урок
> **Spec → Test → Build** — сначала описываем, тестируем на малом, потом строим полное решение
>
> **Один урок = один навык = одно действие** — без перегрузки, только то что применимо сегодня
>
> **Реальный Amazon-кейс в каждом блоке** — не абстракции, а задачи из нашей работы
>
> **Промты как референсы** — копируй, адаптируй, используй прямо сейчас

---

> [!warning] Важно про подход
> Курс — не для того чтобы «знать про Claude». Курс — чтобы **использовать Claude в работе прямо сейчас**. После каждого урока есть конкретное действие. Делай его до перехода к следующему уроку.
