# Урок 1.4 — Стек по умолчанию

> **Зачем:** Каждый раз выбирать стек — потеря времени. Этот урок даёт одно простое правило, которое работает для 90% наших задач.

---

## Три сценария — три решения

| Сценарий | Инструмент | Когда |
|----------|-----------|-------|
| **Проверить идею** | Claude.ai Artifact | Нужен быстрый прототип за 10 минут, не нужна база данных |
| **Реальный инструмент для команды** | **Next.js + Vercel** | Нужно запустить и дать доступ команде |
| **Инструмент с данными и пользователями** | **Next.js + Supabase + Vercel** | Нужна база данных, авторизация, хранение |

---

## Почему Next.js — стандарт

- **Claude Code знает его лучше всего** — генерирует стабильный предсказуемый код
- **Деплой одной командой** на Vercel — без DevOps
- **API Routes** в том же проекте — не нужен отдельный бэкенд
- Нетехнический человек может запустить проект самостоятельно

---

> [!NOTE] Правило
> Начинай с Claude.ai Artifact. Если нужно — переноси на Next.js. Не строй сразу с Supabase если не уверен что нужна база данных.

---

> [!WARNING] Spot the Mistake
> Команда хочет сделать простой инструмент для генерации ответов на отзывы. Начинают с настройки PostgreSQL, Docker, и Express.js бэкенда.
>
> **Что не так?** Для этой задачи достаточно Claude.ai Artifact или простого Next.js проекта. Лишняя сложность замедляет старт и увеличивает риск "не доделать".
