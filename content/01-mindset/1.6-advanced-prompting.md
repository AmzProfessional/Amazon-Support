# Урок 1.6 — Продвинутые техники промтинга

> **Зачем:** Базовые промты из урока 1.1 дают хорошие результаты. Эти три техники дают отличные — особенно для сложных задач. Для тех кто уже работает с Claude регулярно.

---

## Техника 1 — Chain-of-thought: «думай пошагово»

Добавь в промт фразу «думай шаг за шагом» — и Claude показывает ход рассуждений. Результат точнее, особенно для анализа и сравнений.

```
❌ Без CoT:
"Какую стратегию ценообразования выбрать для нашего продукта?"

✅ С CoT:
"Какую стратегию ценообразования выбрать для нашего продукта?
Думай шаг за шагом: сначала проанализируй конкурентов,
затем нашу себестоимость, затем ценовую чувствительность
аудитории — и только потом давай рекомендацию."
```

---

## Техника 2 — Few-shot: примеры внутри промта

Покажи Claude 2–3 примера того что хочешь получить — он подхватывает паттерн точнее чем из описания.

```
Напиши bullet points для наушников в таком стиле:

Пример 1 (наушники премиум):
• 40 часов без подзарядки — работай целую неделю без розетки

Пример 2 (фитнес-трекер):
• Водозащита IP68 — тренируйся под дождём и в бассейне

Теперь напиши 5 bullets для [описание нашего продукта]
```

---

## Техника 3 — Negative prompting: скажи что НЕ делать

Явно запрети то что Claude делает по умолчанию — но тебе не нужно.

```
Напиши ответ на негативный отзыв.

НЕ начинай с "Нам жаль" или "К сожалению".
НЕ используй слово "понимаем".
НЕ обещай то что не можем выполнить.
НЕ делай длиннее 80 слов.
```

---

## Когда применять какую технику

| Задача | Техника |
|--------|---------|
| Анализ, сравнение, выводы | Chain-of-thought |
| Генерация в определённом стиле | Few-shot |
| Когда Claude пишет «не то» снова и снова | Negative prompting |
| Сложная задача | Все три вместе |

> [!WARNING] Spot the Mistake
> Команда хочет получить листинг в стиле конкурента. Пишут: «Напиши как [бренд конкурента], они пишут хорошо».
>
> **Что не так?** Claude не знает как именно пишет этот бренд. Few-shot исправит: скопируй 1–2 примера их текстов в промт и скажи «в таком стиле».
