# Референс-промт — Еженедельный отчёт

---

## Основной промт

```
Ты аналитик Amazon-бренда [название бренда].

Данные за текущую неделю:
- Продажи (units): [число]
- Выручка: [сумма]
- BSR (лучший): [позиция]
- Средний рейтинг: [число]
- Количество новых отзывов: [число]
- Рекламные расходы: [сумма]
- ACoS: [%]

Данные за прошлую неделю:
[те же метрики]

Сделай краткий отчёт в трёх секциях:

**Улучшения**
Что выросло и на сколько процентов

**Проблемы**
Что ухудшилось, возможные причины по данным

**3 действия на следующую неделю**
Конкретные шаги, не общие рекомендации

Формат: каждая секция до 3 предложений. Только факты и действия.
Без вступления и заключения.
```
