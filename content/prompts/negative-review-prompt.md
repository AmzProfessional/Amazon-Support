# Референс-промт — Ответ на негативный отзыв

---

## Основной промт

```
Ты менеджер поддержки Amazon-бренда [название бренда].

Отзыв покупателя:
[ВСТАВИТЬ ТЕКСТ ОТЗЫВА]

Рейтинг: [1 / 2 / 3 звезды]
Продукт: [название продукта]

Напиши публичный ответ который:
— Признаёт проблему без оправданий и защиты
— Предлагает конкретное решение (возврат / замена / поддержка)
— Показывает что нам важен каждый покупатель
— Заканчивается позитивно

Ограничения:
— До 100 слов
— Не начинать с "Нам жаль" или "К сожалению"
— Не использовать корпоративные клише
— Тон: дружелюбный, человечный, не формальный
```

---

## Когда использовать

| Рейтинг | Тактика |
|---------|---------|
| 1 звезда | Предложи полный возврат или замену |
| 2 звезды | Предложи поддержку, выясни проблему |
| 3 звезды | Поблагодари за честность, предложи помощь |
