# Референс-промт — Листинги и SEO

Копируй, заполняй переменные в [скобках], запускай.

---

## Основной промт

```
Ты Amazon-копирайтер с опытом в нише [категория].

Продукт: [название продукта]
Ключевые преимущества: [список 3–5 преимуществ]
Целевая аудитория: [кто покупает, зачем, возраст, ситуация использования]
Главные конкуренты: [необязательно, но помогает]

Создай 3 варианта Title + 5 bullet points.

Вариант A — фокус на цене/ценности (для бюджетного покупателя)
Вариант B — фокус на качестве/премиуме (для требовательного покупателя)
Вариант C — фокус на решении конкретной проблемы

Требования к формату:
- Title: до 200 символов, главное ключевое слово в начале
- Bullets: 1–2 предложения, начинаются с заглавной буквы
- Каждый вариант с отдельным заголовком
- Без маркетинговых клише типа "лучший в мире"
```

---

## Упрощённый промт (для быстрого теста)

```
Ты Amazon-копирайтер. Продукт: [название].
Преимущества: [список]. Аудитория: [кто].

Напиши 1 вариант Title + 5 bullets.
Title до 200 символов. Bullets по 1 предложению.
```
