# Шаблон SPEC.md

Скопируй, заполни, сохрани рядом с проектом.

---

```markdown
## Spec: [название задачи или проекта]

**Цель:** что хотим получить в итоге — одно предложение

**Пользователь:** кто будет этим пользоваться и зачем

**Входные данные:** что у нас есть на входе (текст, файл, данные)

**Результат:** как выглядит готовый вывод — формат, структура, объём

**Ограничения:** что нельзя, какие рамки, что важно учесть

**MVP:** минимальное что решает задачу (что НЕ входит в первую версию)
```

---

## Пример заполненного SPEC

```markdown
## Spec: Анализатор отзывов конкурента

**Цель:** структурированный список инсайтов из отзывов для брифа команде

**Пользователь:** менеджер по продукту, раз в неделю

**Входные данные:** 50–100 отзывов, вставляю вручную текстом

**Результат:** три секции — топ-жалобы / топ-плюсы / незакрытые потребности,
каждая секция до 5 пунктов

**Ограничения:** только факты, без домыслов, без оценочных суждений

**MVP:** один промт, один запуск, один документ на выходе.
НЕ входит: автоматическая загрузка отзывов, интерфейс, история запусков
```
