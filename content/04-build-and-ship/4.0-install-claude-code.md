# Урок 4.0 — Установка Claude Code: Mac и Windows

> **Зачем:** Claude Code работает в терминале — это отдельная программа от claude.ai. Этот урок проведёт тебя через установку шаг за шагом. Занимает 10 минут.

---

## Что тебе понадобится

- Компьютер Mac или Windows
- Подключение к интернету
- Аккаунт на claude.ai (уже есть из урока 0.1)

---

## Установка на Mac

### Шаг 1 — Открой Терминал
Нажми `Cmd + Пробел` → напечатай `Terminal` → Enter

Ты увидишь окно с мигающим курсором. Это нормально — здесь вводятся команды.

> [!TIP] Как выглядит терминал
> Строка вида `имя-компьютера:~ имя$` — это приглашение к вводу.
> Вводишь команду → Enter → видишь результат.

### Шаг 2 — Установи Node.js (если нет)
```bash
node --version
```
Если видишь `v18...` или выше — Node уже есть, пропусти этот шаг.
Если ошибка — скачай с [nodejs.org](https://nodejs.org) → кнопка LTS → установи как обычную программу.

### Шаг 3 — Установи Claude Code
```bash
npm install -g @anthropic-ai/claude-code
```
Подожди 1–2 минуты. Увидишь много текста — это нормально.

### Шаг 4 — Войди в аккаунт
```bash
claude
```
Откроется браузер → войди через свой аккаунт claude.ai → вернись в терминал.

### Шаг 5 — Проверь что всё работает
```bash
claude --version
```
Должна появиться версия типа `1.x.x`. Готово!

## Установка на Windows

### Шаг 1 — Открой PowerShell
Нажми `Win + X` → выбери **Windows PowerShell** (или Terminal)

### Шаг 2 — Установи Node.js
Скачай с [nodejs.org](https://nodejs.org) → кнопка LTS → запусти установщик.
После установки **перезапусти PowerShell**.

### Шаг 3 — Установи Claude Code
```powershell
npm install -g @anthropic-ai/claude-code
```

### Шаг 4 — Войди в аккаунт
```powershell
claude
```
Откроется браузер → войди → вернись в PowerShell.

### Шаг 5 — Проверь
```powershell
claude --version
```

## Как запустить проект

Каждый раз когда работаешь с проектом:

```bash
# 1. Перейди в папку проекта
cd /путь/к/папке/проекта

# 2. Запусти Claude Code
claude

# 3. Начинай работать — пиши задачи как обычно
```

> [!WARNING] Spot the Mistake
> Пользователь установил Claude Code, открывает claude.ai в браузере и ищет там "режим Code".
>
> **Что не так?** Claude Code — это отдельная программа в терминале, не функция сайта. claude.ai и Claude Code — разные инструменты. Для кода открываем терминал, не браузер.
