# Урок 4.3 — Командная работа с Claude

> **Зачем:** Claude — это инструмент для всей команды, не только для одного человека. Этот урок о том как организовать работу без конфликтов.

---

## Роли в проекте

| Роль | Что делает |
|------|-----------|
| **Spec owner** | Пишет и обновляет SPEC.md и README |
| **Tester** | Проводит микро-тесты, фиксирует что работает |
| **Builder** | Работает с Claude Code, итерирует |
| **Reviewer** | Проверяет результат на соответствие spec |

Один человек может совмещать роли.

---

## Правила командной работы с Claude

```
1. CLAUDE.md — один для всей команды, в корне проекта
2. Задачи — маленькие и конкретные ("добавь фильтр по дате",
   не "сделай лучше")
3. Git — коммит после каждого рабочего изменения
4. Вопросы Claude — формулируй как задачи, не как вопросы
```
